# 故障排查

## 找不到播放器或不能移动

启动后在屏幕顶部寻找原图标挂件，向下拉或点击；托盘图标双击也可展开。挂件左右拖动改变位置，展开后可拖顶部标题区域，底边双横线调整长度。布局保存在用户数据目录 `panel-layout.json`；显示器移除后会尝试移到可见区域。

## 桌面歌词不显示

点标题栏“词”打开桌面歌词，也可以在设置里启用。播放有同步歌词的歌曲后会显示当前行；歌词获取失败时可在设置或全屏歌词中重试。确认歌词没有被锁定鼠标穿透，以及保存的窗口位置仍在已连接的屏幕。无歌词的歌曲不会凭空生成歌词。

## 搜索或歌单里有歌曲播不了

“在线未就绪”表示当前检测没有得到完整地址，也没有可用试听或已下载副本，并不证明无法下载；点击可重新解析。具体音源受接口、网络、会员和地区影响。提供歌曲名称或 ID 以及错误提示有助排查，不要提供登录 Cookie。试听片段会单独标识。

## 发现没有歌单

发现页读取网易云公开热门歌单；接口或网络故障时可点刷新重试。若本次运行中已加载过同一批，可能显示缓存并提示离线；这不是私人推荐。歌单内容可能因服务返回的信息不完整而提示部分歌曲未取得。

## 本地歌单或封面

导入是复制，歌单复制、移动、合并和排序操作只调整引用。明确确认“删除本地文件”才会移入系统回收站。不同目录存在同名文件时不会擅自选择；请先区分文件名。封面优先读取文件内嵌图片，其次依歌曲 ID 或严格匹配的标题和歌手查询；无法可靠匹配时使用默认图标。

## 下载音质和任务

下载任务会尽量获取较高质量，但格式和音质由服务返回及权限决定，不保证无损。可在下载任务中查看实际状态并重试。网络或权限失败时保留错误信息，不要将仅有试听片段当成完整音频。

## 日志和验证

用户数据目录通常为 `%APPDATA%/netease-music-desktop-electron`，日志位于 `logs/application.log`。源码开发可运行 `npm run check`、`npm test`、`py -3.12 -m pytest -q tests`；实际 Electron 和打包验证见 [development.md](development.md)。
