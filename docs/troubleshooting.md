# 故障排查

## 没有预览按钮
查看歌曲旁的状态。完整音源显示“在线播放”；只有试听音源显示“试听片段”。暂无音源可点“重试检测”，网络错误不等于永久不可播放。提供歌名或 ID、时间、错误提示，有助于复现。不要提供登录 Cookie。

## 播放中断
在线音频使用流式传输，不自动生成音频缓存。网络连接或签名 URL 失效时，重新点播放会重新解析。下载接口与在线接口是不同链路，下载可用不必然表示匿名在线音源可用。试听时长由服务提供方决定。

## 推荐还是老歌
先确认选中“近期新歌”。其他风格分类保留经典歌曲。近期新歌只接受有真实发行日期且在近一年内的结果；没有新数据时不拿老歌填空。缓存结果会显示缓存日期。换一批耗尽后可重选分类回到第一批。

## 窗口关闭后仍有声音
这是新的后台播放行为。右侧拉手打开抽屉，抽屉底部或系统托盘菜单可完全退出。窗口尺寸按当前显示器工作区约束；连接或移除显示器后重新贴边。

## 日志与开发诊断
日志位于用户数据目录的 logs/application.log。Windows 用户数据目录通常为 %APPDATA%/netease-music-desktop-electron，实际由 Electron 决定。

开发验证：
- npm run check：JavaScript 语法检查。
- npm test：Node 回归测试。
- py -3.12 -m pytest -q tests：Python 回归测试。
- node scripts/probe_online_stream.js：真实匿名音源抽样；仅读取小片段验证传输。
- node scripts/check_recent_online.js：近期新歌和试听片段验证，不保存音频文件。

诊断输出位于本地 .validation/ 时不会提交到仓库。清理源码构建目录不影响音乐文件，但不要删除用户数据目录来“修复”歌曲权限问题。
