# 故障排查

## 找不到播放器或不能移动

程序默认静默待机。轻按右 Shift 打开或隐藏播放器，右上角叉号也可隐藏。右下角系统托盘保留播放器图标，点击可打开，右键菜单可退出。顶部空白区域可以拖动，右下角调整大小。位置保存在 `data/overlay-layout.json`；只有窗口完全移出所有显示器时才恢复到可见区域。普通移动使用原生批量更新；跨屏缩放变化需要系统重新计算。

## 桌面歌词不显示

点底栏“词”打开桌面歌词，也可以在设置里启用；右键“词”锁定或解锁，锁定时鼠标穿透。播放有同步歌词的歌曲后显示当前行，原文和译文逐字出现。全屏保留整句暗字并按演唱逐渐点亮。歌词失败可在设置或全屏中重试；没有歌词或逐字数据时保留整句，不凭空生成文字与时间。

## 搜索或歌单里有歌曲播不了

“在线未就绪”表示当前检测没有得到完整地址，也没有可用试听或已下载副本，并不证明无法下载；点击可重新解析。具体音源受接口、网络、地区及实际授权影响。提供歌曲名称或 ID 以及错误提示有助排查。试听片段在播放时提示。

## 发现没有歌单

发现页读取网易云公开热门歌单；接口或网络故障时可点刷新重试。若本次运行中已加载过同一批，可能显示缓存并提示离线；这不是私人推荐。歌单内容可能因服务返回的信息不完整而提示部分歌曲未取得。

## 本地歌单或封面

“已下载音乐”无需登录即可播放。导入是复制，不移动原文件；同名冲突不会擅自覆盖。封面优先读取内嵌图片，再按可靠元数据匹配。左侧网易云歌单是当前账号的云歌单；收藏可取消，自建歌单删除需确认，默认“喜欢的音乐”用爱心管理。

## 下载音质和任务

下载任务会尽量获取较高质量，但格式和音质由服务返回及权限决定，不保证无损。可在下载任务中查看实际状态并重试。网络或权限失败时保留错误信息，不要将仅有试听片段当成完整音频。

## 日志和验证

解压即用版本的资料在 EXE 旁：`下载` 是音乐，`缓存` 可删除，`data` 与 `playlists` 保留账号、设置和歌单。运行中的程序可能占用缓存，应退出后清理；不要把 data 当作垃圾。日志在缓存目录内。源码与打包验证见 [development.md](development.md)。
