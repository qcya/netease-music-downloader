# 右侧音乐抽屉改造（2026-11-03）

用户已同意保留下载管理窗口，新增日常听歌抽屉，并排查预览和推荐问题。本文件同时记录设计、实施步骤和验证，避免散落多份阶段文档。

## 设计

沿用 Electron、现有下载后端和唯一的主窗口 audio 播放实例。迷你播放器重做为右侧无边框透明窗口：收起仅显示拉手；点击或向左拖动展开；鼠标离开延迟收起；可固定展开。主窗口关闭时隐藏并显示抽屉，退出通过托盘或抽屉菜单完成。主窗口使用自绘标题栏。

抽屉显示封面、歌名、进度、音量、播放按钮，以及当前队列和本地歌单。通过受限 IPC 控制主播放器，避免多个音频实例。屏幕工作区约束坐标，显示器改变后重新贴边。

推荐增加默认“近期新歌”：从公开新歌接口获取，按真实发行日期排序，优先一年内歌曲；日期缺失不伪装为新歌。旧口味分类保留为可选。过期缓存要明确标记。

预览保留流式播放、不自动下载。修复失效检测无法重试、旧 URL 复用和自定义接口失败无官方回退等问题。仅试听/无完整音源继续说明原因，不保证所有歌曲可播。
