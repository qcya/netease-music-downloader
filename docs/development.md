# 顶部悬绳播放器改造

当前版本：2.0.0-preview.2。用户明确要求删除原来的大主界面，使用顶部悬绳、向下展开、可调长度的唯一音乐面板。本文件替代上一轮右侧抽屉方案。

## 架构

- `top_panel.js` 只维护一个主播放器和一个透明挂件。主播放器是唯一 audio 持有者，隐藏不销毁、不停止音频。
- `app/charm.*` 通过 Pointer Capture 发送拖动坐标；主进程验证发送窗口、夹取屏幕工作区坐标，并负责展开动画和布局持久化。拉动距离不足会回弹，点击也可展开。
- `app/panel.*` 承担音乐库、搜索、近期新歌、在线歌单、下载任务和设置。顶部水平移动，底边连续调整高度；长度预设作为辅助入口。
- 主窗口无系统标题栏，Windows 11 22H2+ 使用 Acrylic，其他系统使用深色背景。UI 使用透明底色叠加深蓝灰色层，避免亮壁纸降低可读性。
- `app/panel_player.js` 管理唯一播放实例、序号取消、队列、失败候选跳过与本地文件改名。新选择可取消尚未完成的音源解析和跳歌循环。
- 本地歌词优先，在线歌词仅存在内存。支持可选独立桌面歌词。
- 本地播放会话存储选曲、进度、音量和模式，启动恢复为暂停。面板位置独立保存到用户数据目录 `panel-layout.json`。
- Python 下载后端、下载并发队列、跨音乐目录索引及旧歌单数据格式保留。
- 音源修复：默认播放器过去只查官方匿名接口，下载器却使用两个项目默认服务；现在通过 `music_providers.js` 对齐服务优先级，并以测试验证与 Python 默认值一致。标准音质失效时尝试 higher/exhigh/lossless。已下载的同 ID 曲目优先走本地文件，列表也显示本地可播。

## 范围与取舍

- 用户最新指令覆盖上一轮“保留主窗口”的设计；因此删除旧主窗口、迷你抽屉和沉浸大屏，而不是新增第三套界面。
- 歌单继续兼容 `[歌单] ` 文件名前缀。改名会同步当前队列；如果正在解析文件，则取消旧请求并解析新文件。
- “新发现”只展示近一年有真实发行日期的歌曲。旧口味服务保留为后端兼容代码，不作为新面板的推荐入口。
- 试听播放基于接口实际提供的 URL；只有权限标记、没有音频地址时仍然不可播放。不增加账号绕过或下载兜底。
- 旧界面专用的静态字符串断言随旧界面移除。下载、IPC、音源、歌词、索引、并发和数据持久化等有效回归测试保留；新交互使用实际 Electron 窗口验证。
- 旧版文档和旧界面脚本删除，历史留在 Git 中；不再在当前树中堆叠归档副本。用户音乐和配置不清理。

## 审查与后续限制

执行过程中进行一次独立代码审查，修复三项确认缺陷：音源检测迟到导致抢播、播放准备期间改名恢复旧路径、队列遇不可用曲目停住。另修复关闭拖动中的窗口时访问已销毁对象、播放状态文案未退出“正在连接”。

目前只在本机 Windows 11 环境进行实机检查；Windows 10 深色回退、多种 DPI 和所有多显示器布局仍需要更广泛试用。CDP/窗口截图不能单独证明系统材质，材质另由原生窗口检查确认。没有推送仓库、创建 Release 或对外发布。
