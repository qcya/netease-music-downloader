# 音乐下载器 v1.1.2

## 桌面歌词默认值与记忆
全新使用时默认开启桌面歌词，默认未锁定。手动设置过开关、锁定和位置后，后续启动恢复保存状态，不强制解锁，不重置坐标。升级保留既有设置（包括明确保存的关闭状态）。迷你播放器仍默认关闭。

## 按口味找歌
首页不再从两份随机的大类歌单中抽歌，改为根据明确的歌名、歌手与关键词查询真实曲库资料。默认口味包括术力口与虚拟歌手、B站二创小曲、粤语、欧美电音和华语流行；优先熟悉曲目，少量搭配相关探索。换一批会轮换查询的歌名。歌曲区域放在歌单上方，每首标注选曲方向。
推荐基于本地预设偏好和公开搜索，不读取网易云账号，不上传听歌记录，不冒充平台私人日推或实时B站榜单；也不保证用户认识每一首。曲库缺少的二创不使用同名无关歌曲填充。

## 不可播歌曲不显示播放按钮
歌曲卡片先批量检查当前接口是否提供完整音源。确认可播才显示“在线播放”；无完整音源或仅有试听片段时显示“暂不可播”，不显示播放按钮；网络错误或返回缺失时显示“未确认音源”和“重试检测”，不误判成永久无版权。检测只读取元数据，不下载音频、不打断正在播放的歌曲，短期内存复用并隔离不同接口配置。
在线播放继续使用内存流，不落音频缓存；下载保持独立操作。即使刚通过检测，网络与音源有效期仍可能变化，播放失败会收起按钮并允许重新检测。

## 验收
逻辑回归覆盖首次默认、保存选择、跨接口音源检测、取消隔离、口味配额、去重及离线缓存。浏览器交互测试验证不可播和未知歌曲没有播放按钮。
Windows 成品验收使用合成静音和测试接口，检查无音频缓存的流式播放、独立桌面歌词及最小化同步、锁定坐标保持、真实进程退出后重新启动仍恢复锁定与坐标。真实曲库查询另行探测，不用测试数据代替线上曲目可用性。

请退出旧程序后运行 MusicDownloader-1.1.2-portable.exe。不需要清空歌单、音乐或配置。
