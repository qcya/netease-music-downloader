# 网易云音乐下载器 v2.4.0 · Windows 便携版

这是项目首次公开发布的 Windows x64 单文件便携版（无安装程序）。

## 下载及启动
下载 **MusicDownloader-2.4.0-portable.exe**，在 Windows 10/11 x64 上双击即可运行。EXE 已内置 Electron 桌面界面以及 PyInstaller 打包的 Python 音乐后端，使用时无需另行安装 Node.js、Python 或运行安装脚本。

音乐文件和设置由应用独立管理；“便携版”指无安装 EXE，不保证数据随 EXE 一起携带。用户数据仍可能保存在 Windows 个人资料目录。

## 本次版本
- 搜索、批量下载、下载队列、本地音乐播放和歌单整理。
- FLAC/WAV 等可用的无损音频优先；音源实际不可用时依策略回退并提示，不能保证所有歌曲均可下载。
- 修复本地音频进度条与歌词点击跳转不能定位的问题。
- 双语同步歌词和手势滚动，沉浸播放器。
- 透明桌面歌词默认为关闭，启用后可在设置调整；锁定后鼠标穿透。
- 沉浸播放器和桌面歌词共用白色文字、柔和粉光样式。
- 内置 1080p / 60fps 的柠檬动态视频背景，也可自行更换。
- 以音乐**下载器**为主，本地播放器仅为辅助功能，未恢复搜索结果在线试听入口。

## 文件校验
同目录提供 `MusicDownloader-2.4.0-portable.exe.sha256`，可用 PowerShell 检查：

```powershell
(Get-FileHash .\MusicDownloader-2.4.0-portable.exe -Algorithm SHA256).Hash
```

结果应与 SHA256 文件中的十六进制值一致。
