# 音乐下载器 v1.1.0

## 首页：发现音乐
- 保留搜索，新增「为你发现」：真实公开精选歌单、按本机日期稳定抽样的每日歌曲、换一批、华语/日语/动漫/轻音乐分类。
- 推荐卡片可进入歌单查看歌曲；单曲提供「下载并播放」，复用本地完整文件，不恢复已取消的在线试听。
- 「暂不推荐」会在本机记住忽略的歌曲，可随时重置；不上传个人收听记录，不要求登录。
- 离线时明确标注缓存日期；没有缓存时显示重试与本地随机播放入口，不生成虚构推荐。
- 这些是公开精选抽样，不是网易云账号的私人每日推荐；实际完整下载受音源和接口可用性影响。

## 歌单和音乐库
- 修复默认歌单拖动排序后播放队列混入其他分组，以及命名歌单排序不更新播放队列的问题。
- 跨分类拖动排序在一次元数据写入中保存顺序和归属。
- JSON 保存保留上一份有效备份；损坏记录报错并保留原文件，不再将其当作空歌单覆盖。
- 修改下载目录会登记旧目录，原有歌单仍可访问旧目录音乐；不同目录同名文件明确标记冲突，不冒险播错或删除。
- 本地列表不再静默截断到 1000 首，新增搜索筛选、分批绘制与数量显示。

## 使用体验
- 新增可见的当前播放队列；移出队列不删除文件或歌单关系。
- 歌单可折叠并记住折叠状态，正在播放的歌曲高亮。
- 保留粉蓝外观、四项导航、头像和动态背景；调整底栏布局与焦点行为，关闭沉浸模式时暂停背景视频。
- 保持桌面歌词、迷你播放器、锁定和位置的已保存偏好，首次默认关闭的规则不变。
- 设置中显示版本及构建标识，并提供官方 Release 页面入口。此版本不自动覆盖旧 EXE。

## 验证与范围
构建流水线运行 JavaScript/Python 回归；Windows 打包后测试通过真实鼠标和键盘事件验证歌单编辑，并使用本机测试 API 验证推荐换批、歌单读取、完整合成 WAV 下载、本地解码播放、队列与离线缓存。公开推荐服务可用性另做联网探测，不能用测试 API 成功代替在线可用性保证。

此轮优先完成稳定性与发现页，不包含完整歌曲 UUID 数据库迁移、标签编辑器、均衡器或逐字卡拉 OK。目录间重名时请先区分文件名；大库播放队列面板会明确显示当前附近的窗口范围。

## 升级
关闭旧版本后运行 **MusicDownloader-1.1.0-portable.exe**，无需安装 Python 或 Node.js。原用户设置、歌曲及歌单继续保留。发现数据损坏时不要删除原文件，先保留 `.bak` 和原记录用于恢复。
