# 音乐下载器 v1.0.10

## 修复上一版歌单按钮点击无响应

v1.0.9 的“新建歌单”和“重命名歌单”按钮错误调用了 Electron 不支持的原生 prompt()；先前的修复虽然合并到了 GitHub 源码，却未重新打包到用户下载的 v1.0.9 EXE 中，因此安装版仍无效。

本次 v1.0.10 重新打包包含真正修复的 Windows 程序：
- 使用程序内置输入弹窗替换 prompt()，点击“＋ 新建歌单”可以输入名称并保存。
- 所有新建的歌单和原来的“未分类”歌单均可重命名；空歌单仍然显示默认歌单入口。
- 处理重复名称、非法名称、取消保存、防止重复提交与失败重试。
- 歌单和分类写入原有用户数据文件，退出重启仍保留；不移动、不删除音乐和歌词文件。

## 验收和升级

Windows CI 在打包后启动真实单文件便携 EXE，模拟鼠标点击新建歌单、普通歌单重命名和默认歌单重命名，并读取持久化 JSON 核对；同时验证关闭主窗口不会遗留后台进程。

请确认运行的是 **MusicDownloader-1.0.10-portable.exe**。旧的 v1.0.9 文件不会自动更新；下载新版后关闭旧进程，直接运行新版即可，用户数据保持不变。
