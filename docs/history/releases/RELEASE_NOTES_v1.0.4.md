# 音乐下载器 v1.0.4

Windows 10/11 64 位单文件便携版。可直接替换旧 EXE，不会自动删除歌曲或个人设置。

## 新增功能
- 单曲循环和播放完停止，与顺序、随机、倒序模式共存；手动上一首、下一首仍可使用。
- 我的歌单支持拖动曲目调整播放顺序，顺序保存在本地。
- 自动记录上次播放的歌曲、时间进度和队列；再次启动恢复到原位置，但**默认暂停**。
- 主程序和沉浸播放器：键盘方向键左右切歌，上下以 5% 调整音量；输入框操作不会被抢走方向键。
- 本地歌曲优先读取同名 `.lrc` 歌词，找不到再尝试在线获取。
- 支持导入音乐文件或整个文件夹（递归扫描），音频和同名 `.lrc` 复制到下载目录。原文件保留；重名文件采用新的文件名，不会覆盖已有歌曲。
- 迷你播放器：手动开启的小悬浮控制窗口，可上一首、播放暂停、下一首，默认关闭。

## 修复
- 桌面字幕阴影强度滑块实际控制阴影，而不是只修改无效的 CSS 变量。
- 「无歌词时自动隐藏」与正常显示占位提示的行为分开处理。
- 针对 Windows 悬浮歌词顶部白条：移除原生窗口标题、明确隐藏标题栏和菜单栏、保留完全透明网页背景。此问题与 Windows 窗口合成有关，建议升级后在真实桌面验证效果。

## 下载与升级
下载 **MusicDownloader-1.0.4-portable.exe**，完全退出旧版后运行。发布页面附有 SHA-256 校验文件。重要的音乐与歌词文件建议自行备份。

未恢复在线在线试听入口，仍以下载、本地音乐管理与本地播放为主。
## 发布一致性

已同步修复 Electron 窗口 HTML 标题、主进程标题、EXE 文件版本和 GitHub Release 标签，避免窗口仍显示旧版本号。
