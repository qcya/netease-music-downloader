# 音乐下载器 v1.0.1

Windows 64 位单文件便携版，支持直接运行，无需安装 Python 或 Node.js。

## 本次更新

- **我的歌单**：固定使用一个歌单，自动合并旧歌单曲目，取消“新建歌单”和切换歌单。
- **连续播放**：从歌单点选一首歌曲后，结束时自动播放下一首，最后一首之后回到第一首；不可播放的曲目自动尝试跳过。
- **明确的文件标记**：加入歌单后，音频与同名歌词文件增加 `[歌单] ` 前缀；移出歌单后自动恢复。遇到同名文件不会覆盖。
- **本地删除**：新增“删除”按钮，确认时说明是否为歌单歌曲，删除操作移动到 Windows 回收站，不会直接永久清理。
- **搜索结果简化**：移除不可靠的专辑、时长及来源 ID 字段；播放器播放时间与进度条不受影响。
- **桌面悬浮歌词**：仅在有歌词文本时显示窗口，不再显示等待占位文字，减轻透明窗口的空白显示问题。

## 下载

下载 `MusicDownloader-1.0.1-portable.exe` 并在 Windows 10/11 x64 上直接运行。已有 1.0.0 可关闭后换成新 EXE，用户数据和音乐文件不会因为替换 EXE 而被删除。

同页面提供 `MusicDownloader-1.0.1-portable.exe.sha256`，可核对文件完整性。

## 说明

旧歌单会在首次读取时合并为一个列表，并按规则添加文件名前缀。对有重名冲突或无法移动的文件不会强制覆盖，建议升级前备份重要歌曲和歌词文件。删除歌曲会进入系统回收站。

使用下载内容时请遵守相关版权规定。
