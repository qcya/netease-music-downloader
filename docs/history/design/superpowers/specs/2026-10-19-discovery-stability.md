# v1.1.0：发现音乐与稳定性

用户批准上一轮审查的改进方向，并要求主页推荐歌单与每日随机歌曲。

## 本轮交付边界
保持 Electron + Python、四项导航、粉蓝风格、头像、动态背景、[歌单] 前缀；不恢复在线试听、不自动下载整张歌单、不加入账号登录。第一轮交付稳定核心和主页发现；不把均衡器、逐字歌词、剪辑工具混入本次修改。

主页使用配置的公开 API 返回真实歌单和歌曲；每日以本机日期确定抽样，支持主动换一批、标签和不感兴趣；标明非账号个性化推荐。网络失败使用标明日期的缓存，可显式随机播放本地音乐；从来不把本地数据冒充在线推荐。点歌仅在用户明确点击“下载并播放”后保存最高可用音质并从本地播放。

稳定性包括队列同步与分类原子排序、JSON 损坏保护和备份、保存目录变化后保留旧库定位、取消 1000 首静默截断、分批绘制、可折叠分类和本地筛选、对话框焦点、背景暂停。

每项先写失败测试再实现。最终跑 Node/Python 回归和 Windows 打包后鼠标测试；发布新便携单 EXE，最终答复区分真实在线接口结果、模拟接口自动化和实际成品测试。
