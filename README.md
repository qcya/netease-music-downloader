# 音乐下载器

顶部悬绳播放器，Windows 10/11 x64。当前源码版本 **2.0.0-preview.6**（预览版）。

启动后，屏幕顶部会出现一条悬绳和原图标挂件。按住挂件向下拉，音乐面板从顶部展开。原来的大主窗口和右侧迷你抽屉已移除。

## 怎么用

- **展开、收起**：挂件轻拉超过约 12 像素即可展开；拖动期间整块面板跟随下拉，松手顺滑展开。也可点击；点面板右上角 `⌃` 或按 Esc 收起。收起后音乐继续。
- **调长短**：拖住底边的双横线向上或向下移动。设置内还有紧凑、标准、舒展三个长度。
- **调位置**：收起时左右拖动挂件；展开时拖动顶部标题区域。挂件可到屏幕两侧，面板从挂件所在位置展开，靠边时自动避让屏幕边界；位置、显示器和长度会保存。
- **听歌**：音乐库支持导入文件或文件夹、创建和整理本地歌单；播放队列支持顺序、随机、倒序、单曲循环和播完停止。
- **找歌**：搜索歌曲或歌手；“新发现”显示近一年发行的歌曲。也可以粘贴网易云歌单链接。
- **下载**：歌曲右侧 `↓` 下载单首；“下载当前列表”批量下载。右上角下载入口查看任务、取消或重试。
- **全屏歌词**：点击播放器封面或当前歌词，打开独立的无边框全屏窗口；按 Esc 或点右上角收起，音乐继续播放。全屏中可切歌、暂停、调音量，点击歌词跳转进度。
- **桌面歌词**：设置可开启独立桌面歌词并锁定鼠标穿透。
- **退出**：设置底部“停止播放并退出”，或系统托盘菜单“退出”。

本地歌曲、播放进度、音量和模式会记住；下次启动恢复为暂停，不突然出声。

## 外观与操作

下拉面板使用纯淡蓝背景、白色控件和粉色点缀，只有歌名保留流光；保留原应用图标。透明原生窗口内只有一层实际圆角，展开通过 GPU 合成的位移动画完成，不改变内容高度。动画跟随显示器刷新率，不使用固定 60 帧的窗口缩放定时器。

界面、全屏和桌面歌词使用随程序携带的「星夜浪漫宇宙温柔」字体。全屏恢复原版视频背景、顶部歌曲信息、居中双语发光歌词和底部浮动控制条。设置中可换本地图片/视频、恢复原视频，并调整歌词字色、大小、发光、阴影及原文/翻译显示；已有背景路径和歌词配色继续沿用。

下载任务显示歌名、歌手，以及可获取的进度和速度。旧版本只存编号的历史优先从本地文件名恢复，缺失信息在后台查询。自定义背景不可用时会提示并回退到原版视频，不会删除原来的设置。

播放状态和提示使用中文。普通文字、图标不支持网页式拖选和拖出；搜索、设置和重命名输入框仍可正常编辑、选择和复制。

## 在线预览

优先播放接口实际提供的完整音源；只有试听片段时会明确显示“试听片段”。音频直接流式传输，不会为了预览自动下载整首歌到磁盘。每次播放重新解析音源；失败的自定义接口可回退到公开官方接口。

播放器与下载器使用相同的默认服务。标准音质地址不可用时，播放会尝试其他音质；音乐库中已经下载、文件名带歌曲 ID 的音频优先本地播放。“在线未就绪”只代表在线地址解析未成功，不代表不能下载。

仍有歌曲因版权、会员、地区或接口限制没有音源，不能保证每首歌都能预览。队列遇到不可播放项会尝试后续歌曲，最多遍历一轮，不无限重试。

## 新发现

公开新歌数据按真实发行日期排序，只保留近一年歌曲。无日期的歌曲不冒充新歌；网络失败时明确标记缓存，不拿十年前的经典歌填充。这里不是账号私人日推。

## 运行和构建

普通用户运行 `MusicDownloader-2.0.0-preview.6-portable.exe` 即可，已内置下载后端，无需另装 Python。GitHub [Releases](https://github.com/qcya/netease-music-downloader/releases) 中的旧版不含此界面。

开发需要 Node.js 22+、Python 3.12：

```powershell
npm ci
py -3.12 -m pip install -r skill/requirements.txt -r skill/requirements-build.txt pytest
npm start
npm run check
$env:MUSIC_PYTHON_EXE = (py -3.12 -c 'import sys;print(sys.executable)')
npm test
py -3.12 -m pytest -q tests
npm run build:win
```

构建产物在 `dist/`；也可以使用 `启动桌面版.bat` 和 `构建Windows_EXE.bat`。
