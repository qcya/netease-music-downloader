## 主要功能

- **音乐下载**：搜索歌曲、批量下载、任务队列、失败重试，并显示下载结果和音质信息。
- **本地音乐**：下载后即可播放，支持收藏和自建歌单。
- **同步歌词**：双语歌词分行显示，支持点击歌词定位、滚动浏览和进度条跳转。
- **沉浸播放**：支持 1080p 动态背景，也可以自行选择图片或视频。
- **桌面歌词**：默认关闭，需要时手动开启；支持白色柔光、样式调节、位置锁定和鼠标穿透。

## 下载与运行

普通用户：在 [GitHub Releases](https://github.com/qcya/netease-music-downloader/releases/latest) 下载 `MusicDownloader-1.1.0-portable.exe`，直接双击即可运行。适用于 Windows 10/11 64 位系统，无需安装 Python 或 Node.js。

开发者：使用 Node.js 20+ 与 Python 3.10+。首次运行 `安装依赖.bat`，以后使用 `启动桌面版.bat` 或 `npm start` 启动源码。需要自行生成便携版时可运行 `构建Windows_EXE.bat`。

## 版本说明

**v1.0.0** 是本项目首次正式发布版本。下载是核心功能，本地音乐播放、歌单和同步歌词作为辅助功能。

使用下载内容时，请遵守适用法律和版权规定。

## v1.0.6 更新

- 我的歌单固定为一个，旧歌单记录合并，取消新建和切换歌单的控件。
- 加入歌单时自动在音频和配套 LRC 文件名前添加 `[歌单] `；移出时恢复原文件名，发生文件名冲突时拒绝覆盖原文件。
- 在我的歌单播放歌曲后自动按顺序播放下一首，播完末尾从第一首循环；不可用曲目依次跳过。
- 本地歌曲新增删除按钮，显示歌单成员状态，删除前会提示，删除使用 Windows 回收站。
- 搜索结果仅显示歌名和歌手，不再展示专辑、时长和来源 ID；播放器时间仍正常显示。
- 悬浮歌词仅在有真实同步歌词时显示，停止显示无歌词时的占位白条。

## v1.0.6 播放控制与歌词设置修复

- 播放器增加上一首、下一首按钮，沉浸播放器也可切歌。
- 歌单支持顺序、随机（无重复轮播且保留历史）、倒序播放；播放模式保存在当前电脑。
- 桌面歌词的锁定按钮与开关并排放置，锁定和解锁无需打开设置。
- 桌面歌词与设置页复选框立即响应操作；调整文字外观可在设置页直接预览，点击保存后永久保留。
- 打开软件本身时，悬浮歌词自动避让主界面，不遮挡设置控件；切换到其他应用后才重新显示。
- 新增播放导航和悬浮窗口焦点状态的自动回归测试。

## v1.0.6 功能更新

- 新增单曲循环和播完停止，保留原有顺序、随机、倒序模式。
- 单歌单支持拖动歌曲改变播放顺序，重启后仍保存。
- 记住最后播放的歌曲、进度和队列，下次启动时恢复但保持暂停。
- 主界面和沉浸播放器中使用方向键：左右切换曲目，上下调节音量（输入框聚焦时不会抢按键）。
- 本地播放优先读取同名 .lrc 歌词，找不到时再尝试联网获取。
- 可导入单个或多个音频文件，或导入整个文件夹（包括子文件夹），复制到下载目录，保留原件并复制同名歌词。
- 独立迷你播放器，默认关闭，仅在手动开启时显示。
- 修复桌面歌词阴影滑块未实际生效与无歌词自动隐藏选项不起作用。
- 改进 Windows 悬浮歌词窗口的无边框、原生标题和菜单栏配置，针对顶部白条进行修正（仍需 Windows 实机验证）。

## v1.0.6 紧急修复（启动与退出）

- 主窗口不再只依赖 `ready-to-show`，页面加载完成也可显示；启动超时或加载失败时弹出诊断信息并记录日志。
- 点击主窗口右上角关闭按钮时，同步关闭隐藏的桌面歌词和迷你播放器，并终止运行中的下载后端，避免任务栏消失但后台进程不退出。
- 运行中的程序被再次双击时，激活已有的主窗口，而非重复启动后台实例。
- Windows 发布构建会实际运行打包后的 EXE，检查窗口可见，并发送关闭消息验证没有残留进程。
- 如旧版进程阻止升级，可先在 PowerShell 执行 `Get-Process MusicDownloader -ErrorAction SilentlyContinue | Stop-Process -Force`（会中断当前下载）。

本版不改变歌曲、歌单及个人配置文件，仍建议升级前备份重要歌曲。

## v1.0.6 桌面歌词位置持久化

- 拖动悬浮歌词松开鼠标后自动保存坐标；关闭、再次开启以及重启软件下载都能恢复原来的位置。
- 字体、发光、锁定、窗口宽度及普通设置保存不会将坐标重置。
- 设置页新增独立的「重置歌词位置」按钮，只有主动点击该按钮才会清除自定义坐标并移动到主屏幕上方的默认位置。
- 多显示器环境保留副屏幕负坐标；连接的显示器被移除后保证歌词重新出现在可见屏幕内。
- 自动测试覆盖跨次开启、样式变更、旧设置兼容以及屏幕布局变化。

## v1.0.8 桌面歌词白条专项修复

- 排查确认 Electron 37.2.0 存在 Windows 透明无边框窗口失焦时出现原生标题栏的已知回归问题（Electron issue #46882，官方修复 #47386）。
- Electron 更新至官方修复已合入的 37.3.1；悬浮歌词窗口禁止最大化、最小化、系统缩放及全屏，减少原生窗口装饰状态切换。
- 保留当前歌词的字体、发光、动态大小、位置记忆、拖动、锁定穿透与下载器原有功能。
- 新增代码回归测试以阻止后续不小心退回受影响的 Electron 版本；Windows 便携包继续执行真正 EXE 启动和退出验收。

## v1.0.8 更新：桌面歌词、歌单分类与操作提示

- 开启桌面歌词时，即使音乐下载器是前台窗口，也会显示悬浮歌词，方便实时调整字号、发光及位置；点击“关”仍能隐藏。
- 锁定/解锁独立持久保存：上次锁定则下次锁定，上次解锁则下次保持可拖动；首次使用默认为解锁状态。普通设置保存和样式预览不能偷偷覆盖锁定状态。
- 桌面歌词上次手动拖动的位置沿用，不因开关或焦点变化重置，仍可通过设置里的「重置歌词位置」独立恢复。
- 单个「我的歌单」内部支持创建、重命名和删除分类文件夹；可拖动歌曲到分类标题，也能拖动歌曲调整播放顺序。分类是虚拟的，不实际移动或删除音乐文件；删除分类时歌曲回到「未分类」。
- 错误与操作提示移至窗口右上角，避免挡住右下角的播放器和歌单按钮。
- 播放中调整歌单成员状态会先释放文件句柄，完成重命名后尽可能从原播放进度恢复；发生重名冲突时不会覆盖音频。


## v1.0.9 初次运行与上次状态恢复

首次运行时桌面悬浮歌词关闭、歌词未锁定、迷你播放器关闭。**这些仅是首次安装的默认值**；之后启动必须记住用户最后一次手动设置的桌面歌词开关、锁定状态、歌词窗口位置和迷你播放器开关。退出程序只销毁子窗口和进程，不清除已保存的偏好。

原固定叫「未分类」的默认歌单现在支持重命名；「我的歌单」页支持新建和管理命名歌单。歌单之间可以拖动歌曲调整归属，各歌单可分别顺序播放。命名歌单沿用原虚拟分类数据，不移动音频与歌词、不删除下载目录文件。删除歌单时歌曲进入已重命名的默认歌单。 

## v1.0.10 歌单按钮修复与实际构建

v1.0.9 Release 的 EXE 发布早于歌单弹窗修复，因此运行旧 EXE 时「新建歌单」和「重命名」仍然无响应。请下载 v1.0.10 便携版，运行文件名必须是 `MusicDownloader-1.0.10-portable.exe`，而不是旧 EXE。

v1.0.10 包含应用内歌单名称输入框，支持新建、重命名默认歌单和其他歌单、错误提示与持久保存。Windows 自动化构建同时验证打包后的程序能够启动、完成真实 DOM 点击及 IPC 写入歌单，并在退出后不残留进程。

## v1.1.0 发现音乐与歌单稳定性

主页新增公开精选歌单、按本机日期抽样的每日歌曲、换批、类别切换和「暂不推荐」。不需要网易云登录，也不宣称这是用户账号的私人日推。歌曲需明确点击「下载并播放」后先保存到本地；离线推荐会标注实际缓存日期，可单独随机播放本地音乐。

本轮还修复分类顺序与播放队列同步、保护损坏 JSON、备份有效记录、登记历史下载目录，移除本地列表的 1000 首截断，加入本地筛选、歌单折叠和可见队列。四项导航、粉蓝风格、实际 `[歌单]` 前缀以及桌面歌词/锁定/迷你播放器偏好继续保留。

新增模块：`durable_json.js` 负责安全 JSON；`library_roots.js` 记录音乐目录；`discovery_service.js` 提供公开推荐和缓存；`app/discovery.js`、`app/discovery.css` 为发现页；`app/playlist_queue.js` 负责分类队列协调。

开发验收：`node --test tests/test_*.js`、`PYTHONPATH=skill/scripts python -m pytest -q tests`、`npm run check`。有 Playwright 和 Chromium 的开发环境可运行 `python scripts/verify_browser_ui.py` 生成明确使用测试数据的界面验收图；`node scripts/check_discovery_online.js` 仅探测公开推荐元数据，不下载音频。Windows 构建中的 `scripts/verify_packaged_playlist.js` 对真实 EXE 执行鼠标/键盘/IPC/本地下载播放与离线缓存验收。

变更范围与限制见 `RELEASE_NOTES_v1.1.0.md`。完整歌曲 UUID 数据库与高级音频功能不在本轮迁移内；跨目录同名文件明确报冲突，而非猜测应该操作哪一个。更新仍需下载新 EXE，设置内「获取新版」打开官方 Release 页面。

## v1.1.1 在线播放与桌面歌词
搜索/推荐里的播放按钮现在走纯流式播放，不保存音频文件或 Chromium HTTP 磁盘缓存；下载必须另点下载按钮。在线歌词只保存在内存。桌面歌词新增状态反馈、公开取词来源与后台同步，坏缓存不再阻断获取。使用时需要正常网络及可用音源，不保证所有歌曲匿名可播或绝对零起播等待。详见 RELEASE_NOTES_v1.1.1.md。
