# 音乐下载器

顶部悬绳播放器，适用于 Windows 10/11 x64。当前源码版本 **2.0.0-preview.9**（预览版）。

## 开始使用

- 启动后在屏幕顶部找到原图标挂件；向下轻拉或点击打开播放器，点右上角 `⌃` 或按 Esc 收起，音乐会继续播放。
- 收起时左右拖挂件，展开时拖标题区域移动；拖面板底边调整长度。位置和长度会保存。
- 点封面打开无边框全屏歌词；按 Esc 返回，播放不中断。原版动态背景、双语发光歌词和用户提供的字体保留；可在设置里更换背景、调整歌词样式。
- 标题栏的 **词** 按钮开启或关闭桌面悬浮歌词；在设置中切换“锁定桌面歌词”会立即生效。解锁后按住歌词拖动，右键可锁定、打开设置或关闭；锁定后鼠标穿透，可回设置解除锁定。重新打开时显示当前歌词。
- 设置底部或托盘菜单的“退出”会停止播放并结束程序。

## 我的歌单

“我的歌单”统一管理本地音乐和歌单，不再额外设一页播放队列。**全部已下载**收集可用本地文件；点击歌单标题展开或收起，双击歌曲或点歌曲右侧播放按钮开始播放。控制栏可切换顺序、随机、倒序、单曲循环或播完停止。

- 使用“导入音乐”复制文件或文件夹到音乐目录，不移动源文件；可新建、重命名歌单。
- Ctrl 多选、Shift 连选，或从列表空白处框选；右键选择复制、移动或合并。拖歌曲可排序或移入其他歌单，拖歌单标题可调整歌单顺序。
- 复制、移动和合并修改歌单引用，不重命名或删除音频。删除歌单也保留音频。只有在歌曲右键菜单选择“删除本地文件”并确认后，文件才会移入回收站并从歌单移除。
- 同名文件冲突或已丢失的文件不会擅自选择覆盖；请先在资源管理器中区分或找回文件。
- 歌曲优先显示内嵌封面；没有内嵌图时尝试用歌曲 ID 或严格匹配的歌名与歌手查找，仍无法确认时显示默认图标，不猜测封面。

本地歌曲、播放进度、音量和模式会记住；下次启动恢复为暂停。

## 发现与搜索

“发现”展示网易云公开热门歌单，每页八个；点进歌单查看歌曲并播放，刷新可换一批。热门歌单、手动输入链接或 ID 打开的歌单及搜索结果，每页展示八首，可用上一页和下一页浏览，歌单播放可跨页继续。手动打开歌单沿用配置的接口；如果接口只返回部分歌曲，界面会提示。

已检测到没有可用在线地址、也没有可播放试听片段或本地副本的歌曲，排在**当前页**末尾；其他歌曲保持原有相对顺序。检测未完成或网络错误时保留原位置。标记“在线未就绪”仅表示当前接口未返回可播放地址，不代表无法下载；点击仍可重新尝试。只有试听片段时会明确标注。

热门歌单是公开榜单，不是账号私人推荐。网络或接口故障时可能显示本次运行中缓存的歌单或提示重试；不会编造歌单或歌曲。

## 下载与音源

搜索结果或歌单歌曲右侧 `↓` 下载单曲；“下载当前列表”下载当前显示的歌曲。右上角下载入口显示任务、名称、可获得的进度和速度，并支持取消或重试。

下载会尝试服务提供的较高音质，实际格式和音质取决于服务响应及歌曲权限，**不保证每首都是最高音质或无损**。在线预览流式播放，不为试听自动下载整首；已有同 ID 本地音频会优先用于播放。版权、会员、地区或接口故障可能导致某些歌曲不可播放或下载。

## 运行和构建

普通用户可运行 `MusicDownloader-2.0.0-preview.9-portable.exe`，程序内置下载后端，无需另装 Python。旧版程序请先从托盘退出。GitHub [Releases](https://github.com/qcya/netease-music-downloader/releases) 中的旧版不含本次界面。

开发需要 Node.js 22+、Python 3.12：

```powershell
npm ci
py -3.12 -m pip install -r skill/requirements.txt -r skill/requirements-build.txt pytest
npm start
npm run check
$env:MUSIC_PYTHON_EXE = (py -3.12 -c 'import sys;print(sys.executable)')
npm test
py -3.12 -m pytest -q tests
npm run build:win
```

构建产物在 `dist/`；也可使用 `启动桌面版.bat` 和 `构建Windows_EXE.bat`。

## 仓库导航

| 位置 | 内容 |
|---|---|
| `app/` | 播放器、悬绳和歌词前端 |
| `skill/` | 随程序打包的下载后端 |
| `app/panel.*`、`app/panel_player.js` | 下拉界面与唯一音频播放实例 |
| `app/playlist_selection.js`、`user_playlists.js` | 歌单选择手势、引用与排序 |
| `app/track_order.js`、`popular_playlists.js` | 当前页音源排序、热门歌单 |
| `local_covers.js`、`skill/scripts/` | 本地封面提取与 Python 下载后端 |
| `app/charm.*`、`top_panel.js` | 悬绳、下拉、窗口位置和长度 |
| `app/fullscreen.*`、`fullscreen_player.js` | 独立全屏歌词，只同步主播放器状态 |
| `app/floating-lyrics.*` | 可选桌面歌词 |
| `assets/` | 原应用图标、默认背景和字体 |
| `skill/references/`、`skill/agents/` | 后端说明与 Agent Skill 配置 |
| `.github/workflows/` | Windows 构建和验收 |
| `scripts/`、`tests/` | 构建与回归验证 |
| `docs/development.md`、`docs/troubleshooting.md` | 架构与故障排查 |

缓存、音频、构建产物、依赖和测试截图由 `.gitignore` 排除。用户音乐、歌单和配置保存在用户数据目录及设置指定的音乐目录中。本软件不是网易云官方客户端。
