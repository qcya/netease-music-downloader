# 青春沿岸の音乐播放器

适用于 Windows 10/11 x64 的桌面播放器。当前源码快照为 **2.2.0-preview.10**，原生透明合成仍有黑底问题，尚未修复验收，不作为新版发布；本仓库不是网易云官方客户端。

## 开始使用

1. 将 `青春沿岸の音乐播放器-2.2.0-preview.10-win64.zip` 完整解压到可写目录，运行文件夹中的播放器 EXE。保留旁边的资源和运行库；不要只复制 EXE，也不要直接在压缩包内运行。此版本提供文件夹 ZIP，不使用安装器或自解压单文件。
2. 默认静默启动，在托盘待命。按 **INS** 显示或隐藏播放器，隐藏时音乐继续播放；需要退出时，从托盘菜单选择“退出播放器”。运行新版前先退出旧实例。
3. 拖动窗口顶部的空白区域移动窗口，右下角可调整尺寸。窗口可以部分移出屏幕或越过任务栏，位置与尺寸会保存。
4. 左侧应用图标和名称下方可以切换搜索“歌曲”或“歌单”。主页显示公开推荐与热门歌单封面，点击封面进入歌单；“推荐歌单”旁的刷新图标可重新获取歌单。

界面固定使用 Starry 字体。目标是零背景填充、轻微模糊和细描边；当前预览包虽然通过了 CSS 与窗口属性检查，实际桌面合成出现黑底，属性检查不能证明透明效果正确。该问题仍在本地排查，修复后另行验收。已移除音乐来源选择行、左下五按钮工具栏，以及主题和字体切换功能。

## 已下载音乐

侧栏的 **已下载音乐** 打开平铺的本地歌曲列表，**无需登录或等待网易云接口即可播放**。点击歌曲开始播放；“播放全部”按列表建立播放队列。没有歌曲时，可点击“打开下载目录”放入音乐，或使用“导入音乐”复制本地文件。导入不移动源文件。

- 支持 MP3、FLAC、M4A、OGG、WAV、AAC。本地歌词可与音频同名放置，例如 `歌曲.wav` 与 `歌曲.lrc`。
- 优先使用可确认的本地封面；无法确认时显示默认图标。
- 同名文件冲突或丢失文件不会被擅自覆盖。更换旧版使用的音乐目录前，先确认实际文件的位置。
- 本地歌曲、进度、音量和播放模式会记住；重新启动恢复为暂停。

当前侧栏不再把本地歌单管理与网易云歌单混在一起。旧版本保存的歌单数据会保留，不应为了更新界面手动删除数据目录。

## 网易云账号、歌单与私人 FM

点击左下账号区打开设置并登录；登录后显示该账号的昵称和头像，侧栏读取实际在线歌单及封面。切换账号或退出登录时会清除旧歌单，并丢弃旧请求的迟到结果。未登录时显示登录提示，本地音乐仍可使用。

**私人 FM · 每日随机** 使用网易云官方私人 FM 接口，需登录，并会在连续播放时继续请求歌曲。它取决于账号、接口和服务返回结果，不承诺每次打开都有不同歌曲。

在线歌单封面位于标题左侧，歌曲列表支持连续加载与筛选；当前歌曲以青色轮廓和均衡器标记显示。曲目右侧操作分别用于下一首播放、加入网易云歌单、喜欢和下载：

- **加入网易云歌单** 打开当前账号可写歌单选择框；选定目标后才提交在线添加请求。
- **喜欢** 请求加入账号的网易云喜欢列表，需要有效登录与权限。
- **下载** 保存到本机下载目录，与在线加入歌单是不同操作。

右上返回箭头回到主页；主页中的箭头收起窗口。刷新图标位于“推荐歌单”旁，主页加载失败时也可使用页面中的重试入口。

## 播放、音质与歌词

底栏包含歌曲封面与信息、上一首/播放暂停/下一首、播放模式、紧凑进度条、待播队列、音质、**词** 和音量。

- 模式按钮依次切换 **顺序播放 → 随机播放 → 单曲循环 → 倒序播放 → 播完停止**；每种模式有独立图标与中文提示。
- 音质可请求 **流畅(128k)、标准(192k)、高品质(320k)、无损、Hi-Res**。选项会保存并用于实际在线音源解析；鼠标提示区分请求音质与已确认的实际音质。服务可能回退到较低音质，无法确认时不会声称已获得无损。改变此选项不会重新解析正在播放的本地文件。
- **词** 按钮左键开关桌面歌词，右键切换锁定；右下小锁标记反映锁定状态。锁定后歌词鼠标穿透，可再次右键播放器的“词”解除。解锁后可在歌词文字附近拖动位置。
- 点击歌曲封面打开全屏歌词，按 Esc 返回，音乐继续播放。保留现有全屏背景、双语发光歌词与歌词样式设置。

桌面歌词和全屏歌词共用主播放器的播放状态，不另建音频播放器。歌词存在与否、翻译及同步精度取决于本地 LRC 或接口返回内容。

## 下载与音源限制

公开主页和搜索使用网易云接口；账号歌单、私人 FM 与账号操作使用相应登录状态。登录仅使用账号已有权限，不保证会员歌曲、地区受限歌曲或所有接口都可用。接口可调用不代表每项账号功能都已用真实账号全面验证。

在线播放按所选音质请求音源。普通音源不可用时可能尝试替代服务，已有同 ID 本地音频也可能被用于播放。替代音源可能不可用或无法确认完整性，文件头的时长匹配也不等于已经听验整首内容。

下载后端按服务提供的能力尝试获取音频，**不保证每首都是最高音质或无损**。播放音质选择不等于强制下载后端使用相同规格。版权、会员权限、地区、网络和接口故障都可能导致播放、下载或在线歌单操作失败；程序不会编造歌曲或伪造成功结果。

原项目的网易云 Java API 通过本地管道接入，底层仍保留较广的接口能力；当前可见侧栏只提供主页、私人 FM、已下载音乐和登录账号的实际歌单。原项目来源、许可和依赖见 `upstream/muonium/DESKTOP-NOTICE.md`。

## 文件夹与数据

正常发行版的数据保存在 **EXE 所在目录旁**，建议把整个解压目录放在自己有写入权限的位置：

| 目录 | 用途 |
|---|---|
| `下载/` | 默认下载的音乐与配套文件，也可放入本地音频 |
| `data/` | 程序维护的设置、加密登录状态、窗口布局等内部数据 |
| `playlists/` | 程序维护的歌单及下载历史等内部记录 |
| `缓存/` | 在线音频和歌词缓存、浏览器缓存、日志及临时文件 |

不再默认写入 `C:/Users/.../Music`。升级时保留这些目录；换位置时先退出播放器，再移动整个文件夹。缓存清理针对缓存内容，不能代替删除音乐，也不应删除下载、登录或歌单数据。首次迁移只处理可识别的小型旧数据，不会自动搬运整套音乐文件；旧目录中的音乐应先确认仍然存在。

## 运行和构建

开发需要 Node.js 22+、Python 3.12、JDK 25。构建时通过 jlink 打包 Java 运行环境，最终用户无需另装 Java。

```powershell
npm ci
py -3.12 -m pip install -r skill/requirements.txt -r skill/requirements-build.txt pytest
npm start
npm run check
$env:MUSIC_PYTHON_EXE = (py -3.12 -c 'import sys;print(sys.executable)')
npm test
py -3.12 -m pytest -q tests
npm run build:win
```

也可使用 `启动桌面版.bat` 和 `构建Windows_EXE.bat`。构建 ZIP 位于 `dist/`，包含可完整解压运行的程序文件夹。不要用旧版 portable EXE 的名称或启动方式判断本版是否已经更新。

默认静默待命时不创建播放器渲染器或启动音乐接口后端；隐藏且停止播放后会释放空闲接口进程，再次打开按需重建。开机自启动需在设置中手动开启，使用 `--silent` 参数。

## 原版界面还原与验证

布局以原项目 NCMScreen / NavigateBar / PlaylistPanel / ControlsBar 的逻辑坐标为依据：侧栏约 15%，底栏按本版要求增高至至少 96 像素，保留封面头部、曲目行和紧凑进度条。按本版要求移除来源选择与底部工具栏，并在搜索上方放置应用图标和名称。原始图标字体与 PNG 的来源和摘要记录在 `assets/muonium/sources.json`；运行界面不加载主题配色，也不提供主题切换。

Java/Skija 控件由 Electron DOM 适配，没有在 Electron 中直接执行原版 Java 界面。`scripts/verify_reference_revision.js` 使用隔离账号与接口夹具，实际启动 Electron 验证离线 WAV/LRC、账号切换、音质保存、歌词锁定、五种模式、公共歌单行操作及越过任务栏的窗口拖动；夹具不会向真实账号写入。`scripts/verify_muonium_layout.js` 检查参考布局、字体、连续滚动与 Coverflow。隐藏窗口夹具不代表原生毛玻璃或最终发行包已经通过视觉验收，发行包仍需单独检查。
